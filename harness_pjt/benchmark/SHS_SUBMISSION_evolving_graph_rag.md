## 한 줄 요약

질문을 분석해 최적 검색 경로로 즉시 답하고, 검색 결과와 질문의 관계를 백그라운드에서 학습해 그래프를 계속 진화시키는 self-evolving Graph RAG.

## 주요 아이디어

```
질문 → Analyze (플랜 캐시 → 룰 → 필요시에만 LLM 1콜)
         ├→ 최적 쿼리 경로 (키워드·벡터·그래프 채널 조합 → 확장 → 융합) → Answer
         └→ 검색 기록 + 품질 채점 → 백그라운드 evolving 경로
               → evolving 전략들 (연결 강화/감쇠 · 새 관계 제안 · 전략 재최적화)
               → 그래프(구조·지식)에 반영 → 다음 라운드에 적용
```

- **Analyze — 3단 구조와 전략 재사용** — 본 적 있는 질문은 플랜 캐시에서 즉시(LLM 0회), 전형적 패턴은 룰로, 새롭고 복잡한 질문만 LLM 1콜(재작성+분해+전략 선택을 한 번에). 쿼리를 분해해 골조가 비슷하면 이전에 통했던 전략을 다시 택하므로, 비슷한 질문이 반복될수록 분석 비용 없이 빨라진다.
- **최적 쿼리 경로** — 플랜에 따라 키워드·벡터·그래프 탐색 채널을 조합해 검색하고, 구조 그래프의 이웃 문서로 후보를 넓힌 뒤 융합 랭킹으로 답의 근거를 고른다. 어떤 채널도 완전히 묻히지 않게 채널별 최소 자리를 보장.
- **두 그래프를 함께 진화** — 문서 사이의 구조 관계를 담는 Structure Graph와 의미 지식을 담는 KG를 분리해 두고, 둘 다 evolving 대상으로 관리한다. 구조와 의미가 서로를 오염시키지 않게 저장소부터 나눈 것.
- **evolving의 재료** — 리트리브된 청크와, 그 검색이 원래 질문과 얼마나 잘 맞았는지에 대한 관계 분석(품질 채점)만을 학습 입력으로 쓴다. 채점 기준선은 고정값이 아니라 누적 분포에서 스스로 보정. 잘 맞은 검색만 학습에 쓰고, 어긋난 검색은 재분석 큐로 넘긴다.
- **evolving 전략들** — 자주 함께 맞은 문서는 연결을 강화하고 안 쓰이는 연결은 감쇠, 백그라운드 LLM이 증거를 인용해 새 관계를 제안, 캐시된 전략도 더 나은 대안(섀도 플랜)이 이기면 교체. 진화가 지표를 해치면 체크포인트로 자동 롤백하는 회귀 가드 포함.
- **서빙은 좁게, 관찰은 넓게** — 답은 top-k만 내보내되 학습은 그 아래 랭킹까지 넓게 관찰한다. 서빙 품질은 그대로 두고 evolving 재료만 극대화하는 창 분리. 진화 결과는 다음 라운드에 곧바로 반영 — 돌릴수록 좋아지는 구조가 시스템의 기본 성질.

- 상위 소수(top-5) 정밀도는 변동 폭이 커 안정화 미해결.
