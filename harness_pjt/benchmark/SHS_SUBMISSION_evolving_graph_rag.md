## 한 줄 요약

질문을 분석해 최적 검색 경로로 즉시 답하고, 검색 결과와 질문의 관계를 백그라운드에서 학습해 그래프를 계속 진화시키는 self-evolving Graph RAG.

## 주요 아이디어

```
질문 → Analyze (플랜 캐시 → 룰 → 필요시에만 LLM 1콜)
         ├→ 최적 쿼리 경로 (키워드·벡터·그래프 채널 조합 → 확장 → 융합) → Answer
         └→ 검색 기록 + 품질 채점 → 백그라운드 evolving 경로
               → evolving 전략들 (연결 강화/감쇠 · 새 관계 제안 · 전략 재최적화)
               → 그래프(구조·지식)에 반영 → 다음 라운드에 적용
```

- **Analyze — 3단 구조** — 본 적 있는 질문은 캐시로 즉시(LLM 0회), 전형적 패턴은 룰로, 새 질문만 LLM 1콜. 분해한 골조가 비슷하면 통했던 전략을 재사용.
- **최적 쿼리 경로** — 키워드·벡터·그래프 채널을 조합하고, 구조 그래프 이웃으로 후보를 넓힌 뒤 융합 랭킹으로 근거를 고른다.
- **두 그래프를 함께 진화** — 문서 구조를 담는 Structure Graph와 의미 지식을 담는 KG를 분리해 두고 둘 다 evolving으로 관리.
- **evolving의 재료** — 리트리브된 청크와 질문의 관계 분석(품질 채점)만 학습 입력으로. 잘 맞은 검색만 학습하고, 어긋난 검색은 재분석 큐로.
- **evolving 전략들** — 함께 맞은 문서는 연결 강화, 안 쓰이면 감쇠, LLM이 증거를 인용해 새 관계 제안, 더 나은 전략이 이기면 교체. 지표가 나빠지면 자동 롤백.
- **서빙은 좁게, 관찰은 넓게** — 답은 top-k만, 학습은 그 아래 랭킹까지 관찰. 진화 결과는 다음 라운드에 바로 반영 — 돌릴수록 좋아진다.

## 장점

- fail 7건뿐(pass 38 + partial 55 = 93/100 유효 응답), faithfulness 0.8207이 4-metric 중 최고 — 근거 있는 검색 기록으로만 학습하는 설계가 환각을 억제.
- 돌릴수록 좋아짐 — 내부 retrieval 벤치마크 10회 반복에서 회수 지표 지속 상승(co@10 61→74), 롤백 없이 완주.
- 빠른 서빙 — 비슷한 질문은 LLM 호출 없이 응답(p50 ~40ms), 진화는 전부 백그라운드라 지연에 영향 없음.

## 단점

- evidence_precision 0.6770으로 최저 — 회수를 넓게 가져가는 대가로 불필요 근거가 섞임. partial 55건의 주요 원인 추정.
- 상위 소수(top-5) 정밀도의 변동 폭이 큼.
- 진화 효과는 질문 누적에 비례 — 콜드 스타트 직후엔 일반 RAG와 차이가 작다.

- 벤치마크 정답을 참조하는 학습은 금지 — evolving 시 쿼리·청크·검색 결과라는 객관적 증거만 사용.
