## 한 줄 요약

질문을 분석해 최적 검색 경로로 즉시 답하고, 검색 결과와 질문의 관계를 백그라운드에서 학습해 그래프를 계속 진화시키는 self-evolving Graph RAG.

## 주요 아이디어

```
질문 → Analyze ─→ 최적 쿼리 경로 ─→ Answer
              └→ 백그라운드 evolving 경로
                    → evolving 전략들 (강화 / 감쇠 / 보강)
                    → 그래프에 반영 → 다음 라운드에 적용
```

- **두 갈래 파이프라인** — 질문이 들어오면 Analyze가 최적 쿼리 경로(키워드·벡터·그래프 탐색의 조합)를 골라 바로 답을 만들고, 같은 검색 기록이 백그라운드 evolving 경로로도 흘러간다. 서빙은 빠르게, 학습은 뒤에서 따로.
- **두 그래프를 함께 진화** — 문서 사이의 구조 관계를 담는 Structure Graph와 의미 지식을 담는 KG를 분리해 두고, 둘 다 evolving 대상으로 관리한다. 구조와 의미가 서로를 오염시키지 않게 저장소부터 나눈 것.
- **evolving의 재료** — 리트리브된 청크와, 그 검색이 원래 질문과 얼마나 잘 맞았는지에 대한 관계 분석만을 학습 입력으로 쓴다. 잘 맞은 검색은 그래프 연결을 강화하고, 어긋난 검색은 재분석 대상으로 넘긴다.
- **전략의 선택과 재사용** — 쿼리를 분해해 보고 골조가 비슷한 질문이면 이전에 통했던 검색 전략을 다시 택한다. 비슷한 질문이 반복될수록 분석 비용 없이 점점 빨라진다.
- **다음 라운드에 적용** — evolving 결과(그래프 보강, 전략 갱신)는 다음 검색 라운드에 곧바로 반영된다. 돌릴수록 좋아지는 구조가 시스템의 기본 성질.
